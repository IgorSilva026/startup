# Fluxon Analytics — Landing Page

Este repositório contém o código-fonte da landing page da startup **Fluxon Analytics**.

## Regras do repositório

Toda alteração feita neste projeto — seja no código, no conteúdo ou na estrutura do site — **é obrigatoriamente commitada**. Isso é o que garante que a equipe tenha controle total sobre tudo que está sendo feito no sistema.

### Commits

- Todo commit deve ter uma mensagem **clara e específica**, descrevendo exatamente o que foi alterado.
- Commits genéricos (ex: `"ajustes"`, `"fix"`, `"update"`) **não serão aceitos**.
- Se o commit não seguir os padrões definidos pela equipe, a branch **será travada** até que o código seja revisado e corrigido.

### Uso de Inteligência Artificial

O uso de IA para gerar ou apoiar o código é permitido, mas quem commitar precisa **entender e dominar o que foi alterado**. Serão feitas perguntas sobre as mudanças enviadas — não é aceitável commitar código que você não sabe explicar.

### Documentação das alterações

Toda alteração relevante feita no projeto deve ser registrada neste README (ou no changelog do projeto), descrevendo o que foi feito. Isso mantém o histórico do site organizado e acessível para toda a equipe.
